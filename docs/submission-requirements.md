# 제주 SW미래채움 센터 마스터과정 과제 제출 요구 정리

## 안내문 핵심 정보

| 항목 | 내용 |
|---|---|
| 과제 주제 | AI를 활용하여 바이브 코딩으로 웹앱 만들기 |
| 웹앱 주제 | 자유 선택 |
| 필수 조건 | Vercel 배포 URL에서 오류 없이 웹앱이 실행되어야 함 |
| 제출 기한 | 2026-08-26(수) 오후 11시 59분까지 |
| 제출 방법 | Liveclass 내 커뮤니티 `1일차 강의 '과제'`란에 제출 |

## 필수 제출 항목

| 번호 | 제출물 | 비고 |
|---|---|---|
| 1 | 자신이 만든 웹앱 설명서 PDF | AI 사용 작성 가능 |
| 2 | 자신이 만든 웹앱의 PRD PDF | AI 사용 작성 가능 |
| 3 | 자신이 만든 웹앱의 GitHub Repository URL | 완성 코드 업로드 필요 |
| 4 | 자신이 만든 웹앱의 Vercel 배포 URL | 실제 동작 URL 필요 |
| 5 | Vercel에서 3번 GitHub Repository를 사용했다는 인증 사진 | Git Import 증빙 캡처 필요 |

## 웹앱 설명서 필수 포함 항목

| 항목 | 설명 |
|---|---|
| 웹앱 제목 | 앱 이름 |
| 제작 의도 | 이 웹앱을 만든 이유 |
| 전체 아키텍처 | 메뉴 구성, dataflow, workflow 등 구성도 |
| 기술 스택 | 웹앱 제작에 사용된 기술 |
| 사용 프롬프트 예시 | AI를 활용한 제작 과정 증빙 |
| 제작 소감 | PMI(Plus, Minus, Interest) 형식 |

## 평가 기준 매핑

| 평가 항목 | 배점 | 현재 프로젝트에서 준비해야 할 증빙 |
|---|---:|---|
| 웹앱 설명서 | 20점 | 설명서 Markdown·PDF, 아키텍처 다이어그램, 프롬프트 예시, PMI |
| 웹앱 PRD | 10점 | PRD Markdown·PDF |
| GitHub URL | 30점 | 정리된 소스 코드, README, 업로드 가이드 |
| Vercel URL | 20점 | 외부 배포 호환 코드, 환경 변수 안내, 실제 배포 확인 |
| Git Import 증빙 사진 | 10점 | Vercel 새 프로젝트에서 GitHub 저장소를 Import한 화면 캡처 안내 |
| 오류 없는 실행 | 10점 | 빌드·테스트 통과, 배포 후 핵심 흐름 점검 |

## 현재 해석

이 과제는 단순히 웹앱 기능만 만드는 것이 아니라, **문서(PRD·설명서) + 코드(GitHub) + 실제 배포(Vercel URL) + 배포 증빙 캡처**까지 포함한 제출 패키지를 요구한다. 따라서 이후 작업은 Manus 내부 동작만 맞추는 수준이 아니라, Vercel에서 실제 구동 가능한 구조와 초보자용 배포 가이드까지 포함해 완성해야 한다.
